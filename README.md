# 🌌 Jeewan Giri - Galaxy Portfolio

A stunning, space-themed portfolio website featuring animated stars, nebula effects, and cosmic design elements. Built with React, TypeScript, and Framer Motion.

## ✨ Features

### 🎨 **Galaxy Theme Design**
- **Animated Star Field** - Canvas-based twinkling stars
- **Nebula Effects** - Floating, animated cosmic clouds
- **Shooting Stars** - Periodic meteor animations
- **Cosmic Color Palette** - Purple, blue, pink nebula colors
- **Space Fonts** - Orbitron & Space Grotesk typography

### 🚀 **Sections**

1. **Hero Section**
   - Profile photo with rotating border animation
   - Animated gradient text
   - Stats cards (Experience, Projects, Dedication)
   - Social media links
   - Smooth scroll indicator

2. **About Section**
   - Professional summary
   - Icon-based stats grid
   - Cosmic card design

3. **Skills Section**
   - Categorized skill cards
   - Icon + tag display
   - Hover glow effects
   - Additional skills showcase

4. **Experience Section**
   - Timeline layout
   - WHO project highlights
   - Technology tags
   - Cosmic card design

5. **Projects Section**
   - Featured project cards
   - Gradient project visuals
   - Technology badges
   - GitHub & demo links

6. **Contact Section**
   - Contact form with cosmic styling
   - Contact info cards
   - Email, GitHub, LinkedIn links

7. **Footer**
   - Gradient divider
   - Quick navigation links
   - Animated heart icon

### 🎭 **Animations & Effects**

- **Canvas Star Animation** - 200+ twinkling stars
- **Nebula Floating** - Smooth, infinite loop animations
- **Shooting Stars** - Periodic meteor effects
- **Profile Border Rotation** - 360° gradient border
- **Hover Effects** - Scale, glow, and transform animations
- **Scroll Animations** - Staggered fade-in effects
- **Gradient Shifts** - Animated color transitions

- **Framer Motion** - Advanced animations

## 🎨 **Customization**

### Change Colors
Edit `src/index.css`:
```css
:root {
  --color-nebula-purple: #your-color;
  --color-nebula-blue: #your-color;
  --color-nebula-pink: #your-color;
}
```

### Modify Star Count
Edit `src/components/BackgroundEffects.tsx`:
```typescript
for (let i = 0; i < 200; i++) { // Change number
  // Star creation
}
```

### Update Profile Photo
Replace `/public/profile.jpg` with your photo
